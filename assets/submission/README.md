# Submission artwork

[MeowWatch cover](meowwatch-devpost-1200x800.png) is a **1200 × 800 px, 3:2**
gallery thumbnail. It uses the selected A cat-and-play mark and the tagline
“Movie night, even when you’re miles apart.” in the final navy, cream and blue
palette. There are no screenshots, purchase claims or unverified device claims.

- `meowwatch-devpost-1200x800.png`: opaque upload-ready PNG.
- `meowwatch-devpost-1200x800.svg`: editable typography and vector logo, with
  embedded versions of the bundled DM Sans and DM Serif Display fonts.
- `meowwatch-devpost-1200x800-outlined.svg`: portable vector export with text
  converted to paths; this is the exact source used for the PNG.
- `manifest.json`: sizes, text bounds, renderer versions and source/output hashes.

Use the existing [1024 px app icon](../brand/meowwatch-1024.png) when the form
asks for the application icon. It is separate from this rectangular cover.

The editable SVG includes the full font license notices in its metadata.
The embedded fonts retain the SIL Open Font License. See
[DM Sans](../fonts/DMSans-OFL.txt) and
[DM Serif Display](../fonts/DMSerifDisplay-OFL.txt).

## Native Android screenshot

[Native home screen](meowwatch-android-1179x2556.png) is an original
**1179 × 2556 px PNG** captured from the production app on an **Android API 35
x86_64 emulator**. It shows the free-customer home after onboarding. The
emulator display was configured to that size before capture. The file is copied
byte for byte from the CI artifact: no resizing, cropping, frame or retouching.

This screenshot is separate from the typeset cover artwork above. Its
[provenance](screenshot-provenance.json) records the exact source commit,
[run 35212468110](https://github.com/PeterShanxin/MeowWatch-Mobile/actions/runs/35212468110),
artifact-relative path, APK and image hashes, dimensions and runtime.

The source workflow passed all twelve recorded emulator acceptance stages. It
covered one free host and two distinct paid hosts with a real TLS peer, native
Test Store cancellation, simulated failure and successful purchase,
same-customer restore after customer-info cache invalidation, Glass Aurora
persistence and paid-room usability, a Movie night premium reaction sent in
the production UI and received by the independent headless TLS peer, and
Cinema Noir persistence. This is one native Android player with a headless
peer, not two native devices. The restore evidence does not cover reinstall or
lost-identity recovery. The screenshot itself establishes the rendered home
screen, and the run does not establish physical-device rendering. This
original capture is not regenerated by the artwork tool.

The selected home PNG is unobscured. Review found no unexpected OS modal in
the three raw recordings, but the segment boundaries retain measured coverage
gaps. The screenshot does not establish that the recordings form one
uninterrupted demo.

## Regenerate

```powershell
npm install --prefix .local/submission-artwork-tools --no-save --package-lock=false sharp@0.35.4 opentype.js@1.3.4
$env:NODE_PATH = Join-Path (Get-Location) '.local/submission-artwork-tools/node_modules'
node tools/generate_submission_artwork.cjs
```

The generator reads the approved icon and repository fonts; it makes no network
or image-generation request. Edit its text and layout constants to revise the
composition. The outlined version avoids font substitution in SVG renderers
that do not support embedded fonts. Artwork readiness does not establish
submission eligibility or completed product acceptance.
